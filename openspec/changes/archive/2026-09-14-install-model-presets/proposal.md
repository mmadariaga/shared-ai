## Why

Customizing models per project is repetitive; presets let users snapshot a working project configuration under `<harness>/sai/presets/<name>.json` and restore it to any project without touching globals. The post-setup menu now offers Save preset and Load preset flows that preview the ALL model table and gate writes behind explicit confirmations.

## What Changes

- bin/model-customization.js: MENU_OPTIONS gains Save preset and Load preset entries, with harness routing to save-preset and load-preset screens backed by per-harness preset directories.
- Save flow prompts a preset name, validates containment via resolvePresetPath, renders a read-only ALL-table preview via allTableHeader plus effective settings, requires a Yes save confirmation plus a second overwrite confirmation when the name exists, snapshots the full effective project map via effectiveRawSetting, and writes atomically to `<harness>/sai/presets/<name>.json`.
- Load flow lists saved names via listPresetNames with an empty-state message when none exist, parses JSON with a visible corrupt error and no partial apply, ignores unknown keys and preserves current values for missing keys, previews the resulting ALL table via formatRawSetting, requires a Yes apply confirmation, and applies to project-local overrides only via createLocalOverride.
- Harness isolation, cancel-no-mutate, corrupt-no-partial, and separator containment hold across both flows; declines preserve originals and cancels mutate nothing.
- test/model-customization-menu.test.js: production promptChoice invocation count updated from seven to eleven to cover menu, harness, scope, save confirm, save overwrite, load selector, load confirm, and the existing settings selectors.

## Capabilities

### New Capabilities

- `install-model-presets`: global per-harness preset library with save and load flows, ALL-table preview plus confirmations, project-only apply, containment, corrupt blocking, and key-drift tolerance.

### Modified Capabilities

- `model-customization-menu`: post-setup menu expands to include Save preset and Load preset actions with harness routing and eleven production promptChoice invocations.
