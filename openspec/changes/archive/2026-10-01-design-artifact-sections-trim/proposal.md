> **⚠ POST-HOC RECORD** — This proposal was backfilled after implementation against a user-supplied statement of intent. It describes a decision already made, not one being proposed.

## Why

Measured over 236 real designs, `## Deferred` mostly restates Non-Goals and Risks and has no consumer, 20 of 23 sampled Manual Verification items duplicate automated tests, and 36% of Migration Plans open with "no migration needed" (`openspec/schemas/sai-workflow/templates/design.md`, `sai/commands/design/steps/design.md`). The sections cost generation effort and reader attention without informing any downstream phase.

## What Changes

- **BREAKING**: `design.md` no longer carries a `## Deferred` section; the design template, the design step's required sections, and the glossary term "Deferred Decision" are removed.
- `design.md`'s `## Manual Verification` becomes a hard filter: only checks no automated test in the plan covers (and `/sai-5-review` does not already cover); otherwise `None` plus a one-line reason. The two qualifying classes stay: generated-artifact drift and end-to-end smoke across real runtimes.
- `design.md`'s `## Migration Plan` becomes conditional: emitted only for schema/data migration, deploy ordering, feature flags, or rollback; otherwise omitted, never a "no migration needed" placeholder.
- `sai/commands/design/steps/tasks.md`: a real follow-up is recorded in `## Goals / Non-Goals` as "out of scope: X — revisit when Y"; it is not an Open Question and does not block `tasks.md` generation.
- Both design contract tests drop `## Deferred` from `DESIGN_TOP_LEVEL_SKELETON`.
- Live specs swept in the same change: `design-deferred-decisions` retired (all requirements removed), `design-manual-verification`, `sai-workflow-schema`, and `design-target-state` modified (the last only to stop referencing the retired capability), `design-section-contract` added.

## Capabilities

### New Capabilities
- `design-section-contract`: design.md omits Deferred, records follow-ups as non-goals, and emits Migration Plan only when a real rollout concern exists.

### Modified Capabilities
- `design-manual-verification`: Manual Verification restricted to checks no automated test in the plan covers.
- `sai-workflow-schema`: design template skeleton no longer lists Deferred and marks Migration Plan conditional.
- `design-target-state`: the Target State None provision references `design-manual-verification` alone, no longer the retired `design-deferred-decisions`.
- `design-deferred-decisions`: every requirement removed; capability retired.

## Impact

- Modified: `GLOSSARY.md`, `openspec/schemas/sai-workflow/templates/design.md`, `sai/commands/design/steps/design.md`, `sai/commands/design/steps/tasks.md`, `test/change-overview-contract.test.js`, `test/design-coordinator-worker.test.js`.
- Specs: new `openspec/specs/design-section-contract/spec.md`; modified `design-manual-verification`, `sai-workflow-schema`, `design-target-state`; retired `design-deferred-decisions`.
- Both harnesses (Claude Code and opencode) are covered; the step files and template are shared. `sai/commands/implement/**` is untouched.
Out of scope: design.md, tasks.md, implementation.md — not generated by /sai-backfill

## Request Additional Notes

Future scope, outside this change (sai-3/sai-4 change): `sai/commands/implement/steps/plan-generation.md` turns every non-`None` Manual Verification item into a human-check `- [ ]` checkbox at the Step where it becomes observable; `sai/commands/implement/steps/validation.md` checks each item is carried or explicitly explained; `implementation-plan.template.md` is updated accordingly. When `## Migration Plan` is present, plan generation reflects its ordering and rollback constraints (a Step order or an explicit note).

## Additional Notes

Known limitations: until the sai-3/sai-4 change ships, a non-`None` Manual Verification item and a present Migration Plan still have no consumer in implement, as today. Fix-loop history: round 1 found the glossary "Deferred Decision" entry still pointing at `## Deferred` (entry removed) and the Manual Verification bullet missing its two qualifying check classes (restored); round 2 converged with no findings.
