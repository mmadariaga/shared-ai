## Why

GREEN stops correctly on test contradictions but the coordinator has no hands today: an out-of-scope hand-back spends zero attempts and meta-build forces full implement re-entry, turning cases like the installer-user-activation Step 2 RED-adapter stall into manual work.

## What Changes

- Coordinator locus gains the RED-owner sub-case: a GREEN blocking-contradiction proving a test-infra point (setup, adapter, seed, import wiring) resumes the same-Step RED owner with continue_after_recovery without a prior hand-back and preserves blindness.
- New coordinator-led unblock ladder section: escalation as RED-owner retry, then last-resort infra fix, then human dead-end, never a single hard STOP; commit and coordinator-verification gates unchanged and assertions never relaxed.
- Runner routing: a GREEN blocking-contradiction proving a test-infra point routes as an in-scope RED-owner correction before any hand-back, spending one ledger slot for a new key and zero for a duplicate.
- Meta-build re-entry: implement collapse remains the default, while a human-authorized retry reuses the current implementation.md and worktree state without a full collapse only when the plan is unchanged and checkbox state is preserved.

## Capabilities

### New Capabilities

- `auto-redispatch`: RED retry of the same Step on a GREEN test-infra contradiction without a prior hand-back, with ordered diagnosis keys and duplicate-key zero spend.
- `last-resort-fix`: Coordinator-owned test setup, adapter, or seed fix only when the RED owner retry is unpassable and no RED or GREEN safe path remains, never assertion bodies.
- `human-override`: Explicit human unblock order re-attempts a viable block with a new diagnosis key and opens the new invocation itself while reusing plan and worktree state.
- `cheap-reentry`: Reuse of implementation.md and worktree state when the plan is unchanged, with normal collapse when the plan changed.

### Modified Capabilities

None.

## Impact

- `sai/commands/apply/coordinator.md` — RED-owner locus sub-case plus new coordinator-led unblock ladder (auto retry, last-resort infra fix, human override).
- `sai/commands/apply/runner.md` — GREEN infra-contradiction routing to same-Step RED-owner correction.
- `sai/commands/meta-build/coordinator.md` — cheap re-entry reusing unchanged plan and worktree state.
- Out of scope: design.md, tasks.md, implementation.md — not generated by /sai-backfill
