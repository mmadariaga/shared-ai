## Why
Users cannot discover the example model maps today, and a fresh install drops them entirely because sai/install-manifest.json has no preset projection. Shipping the four opencode examples as documented copy-if-absent seeding makes per-project tuning repeatable without touching Claude surfaces or Save/Load flows.
## What Changes
Added sai/presets/opencode/ with GO.json, GO+OC-FREE.json, OAI-LUNA+OC-FREE.json, OAI-SOL+OAI-LUNA+OC-FREE.json. Added the opencode-preset-examples copy-if-absent projection in sai/install-manifest.json projecting sai/presets/opencode to the opencode sai presets library with the harness segment stripped. Extended bin/install-manifest.js STRATEGIES with copy-if-absent, added the copy-if-absent branch in bin/install-flow.js installProjection, made bin/doctor.js treat copy-if-absent absences as warn presets instead of fatal missing, propagated strategy in bin/uninstall-flow.js manifestEntries, added a README Example presets subsection with a 4-row table plus Load preset line, and updated the three inventory tests to expect the four new opencode-specific sources.
## Capabilities
### New Capabilities
- preset-docs: README table of the four opencode examples with usage guidance and Load preset line.
- preset-install: copy-if-absent projection of sai/presets/opencode/ into the opencode preset library, never overwriting existing files.
### Modified Capabilities
- None.
