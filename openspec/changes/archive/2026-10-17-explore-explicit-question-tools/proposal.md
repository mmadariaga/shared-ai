## Why

Some Explore questions relied on previously loaded general instructions or neighboring question definitions to select the correct presentation tool. The implementation makes the native-picker requirement explicit at each applicable definition, without changing the questions themselves.

## What Changes

- Add question-local references to the "Closed-choice prompts" rule in `sai/policies/remember.md`, naming `AskUserQuestion` on Claude Code and `question` on opencode.
- Cover issue drift and shortcut questions, open decisions, language gates, maturity and later-stage selectors, route and optional-action questions, recovery questions, escalated planning questions, and per-change review selection.
- Preserve question-specific context, labels, choices, ordering, applicability, skip conditions, conversational exceptions, and the shared fallback rule.
- Add definition-bounded regression assertions for both changed and already-complete question definitions, including multiple questions in one file. Demonstrate that a neighboring question cannot supply a missing local requirement.
- Protect plain conversational review and list-agreement questions and shared picker-unavailable and capacity fallbacks. Update existing assertions to recognize the explicit wording and the exact route-picker section boundary.

## Capabilities

### New Capabilities

- `explore-question-presentation`: Question-local native-picker instructions and definition-bounded regression coverage across Explore step definitions.

### Modified Capabilities

None. Existing route, optional-action, escalation, review, and crystallization behavior remains unchanged; the new capability specifies the added instruction-local explicitness and its regression checks.
