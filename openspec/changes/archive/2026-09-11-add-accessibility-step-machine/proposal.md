## Why

`sai/commands/accessibility/coordinator.md:29-39` is the last audit coordinator still carrying a hand-written pointer table and continuation prose. Spec, design, implement, review, security, and performance already route through `sai-state` step machines. Moving accessibility's routing to a registered step machine (`accessibility-standalone@1`) brings it into parity with the machine-routed coordinators and consolidates routing data into registered machines rather than coordinator prose.

## What Changes

- **New file:** `sai-state/machines/accessibility-standalone.js` — a data module built by the linear-step factory that owns stateful stage routing for standalone accessibility runs and chained accessibility segments in `/sai-review`. Declares five steps: `resolve-accessibility-scope` (fileless), `map-ui-framework`, `resolve-static-audit`, `resolve-runtime-audit`, `close-accessibility-outcome`.

- **Updated file:** `sai-state/registry.js` — registers `accessibility-standalone@1` machine alongside existing standalone machines (spec, design, implement, review, security, performance).

- **Updated file:** `sai/commands/accessibility/coordinator.md` — replaces the static `step_pointer_map` table (lines 29-39) with a `step_machine: accessibility-standalone@1` declaration. Adds a fetch for `@sai/policies/stage-machine.md` to own continuation behavior. Updates the `replacement_reconstruction_fields` documentation to reference the step machine instead of the static map.

- **Test updates:** Modified `test/linear-step-machines.test.js`, `test/accessibility-coordinator-worker.test.js`, and `test/step-machine-wiring.test.js` to include accessibility-standalone@1 in machine registration and discovery validation tests. A seven-coordinator discovery scenario is added to step-machine-wiring-verification.

## Capabilities

### New Capabilities

- **accessibility-standalone-loading** — Accessibility's step machine governs every activation of the accessibility adapter, direct (`/sai-8-accessibility`) and chained (as an audit segment of a chained `/sai-review` invocation). No shared sessions or state exist between activations.

### Modified Capabilities

- **accessibility-step-gated-delivery** — Static step pointer map is replaced by step machine architecture. Pointer continuations are now delivered through the step machine via `@sai/policies/stage-machine.md`.

- **coordinator-step-pointers** — Accessibility moves from the static-map list to the step_machine list, joining implement, review, security, and performance in the two-routed-phases requirement.

- **step-machine-wiring-verification** — Accessibility coordinator discovery and validation now includes accessibility alongside spec, design, implement, review, security, and performance (seven coordinators total).
