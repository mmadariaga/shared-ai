> **⚠ POST-HOC RECORD** — This proposal was backfilled after implementation against a user-supplied statement of intent. It describes a decision already made, not one being proposed.

## Why
Backfill classified three genuinely new requirements as MODIFIED, and format-only schema and coordinator checks let the bad draft through until archive failed late with a spec-update error. A deterministic early check plus a narrow late fix removes that late-failure class without changing install or projection surfaces.

## What Changes
- Clarified the Phase 6c delta-header rule to per-requirement verbatim existence in `sai/commands/backfill/instructions.md`, so ADDED means absent from the main spec and MODIFIED or REMOVED means present.
- Added a mandatory coordinator-owned pre-write preflight in `sai/commands/backfill/coordinator.md` that stages drafts to OS-temp and runs the new header script before any write.
- Added a classified single-retry content-fix loop in `sai/commands/archive/coordinator.md` that reroutes only content errors with a cited Requirement header to the same backfill worker and retries archive exactly once.
- Added the same-worker header-fix continuation in `sai/commands/backfill/worker.md` that moves only cited requirement blocks between delta sections and never regenerates or writes files.
- Added the deterministic checker `sai/tools/check-delta-headers.js` with verbatim set-diff semantics and single exit codes for pass, misclassification, and tooling failure.

## Capabilities
### New Capabilities
- `delta-header-preflight`: deterministic ADDED, MODIFIED, and REMOVED existence check before backfill writes, including the script, the clarified per-requirement rule, and the mandatory pre-write gate.
- `archive-content-recovery`: classified single-retry reroute to the same backfill worker on content failures with cited headers only, including validation, one retry, and explicit non-reroute cases.

### Modified Capabilities
- None. Overlapping existing specs were detected by delegated scan and are carried above as informational context for archive-time synchronization; no deltas for existing mains are drafted in this backfill.

## Impact
- New: `sai/tools/check-delta-headers.js` (deterministic header preflight, exit 0 pass, exit 1 misclassified, exit 2 usage or IO error).
- Modified: `sai/commands/backfill/instructions.md` (Phase 6c per-requirement existence rule).
- Modified: `sai/commands/backfill/coordinator.md` (mandatory OS-temp staged preflight before writes).
- Modified: `sai/commands/backfill/worker.md` (header-fix continuation, headers only, read-only).
- Modified: `sai/commands/archive/coordinator.md` (classified content-fix loop with single retry bound).
Out of scope: design.md, tasks.md, implementation.md — not generated by /sai-backfill
