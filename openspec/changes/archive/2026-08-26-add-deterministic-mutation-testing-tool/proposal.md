## Why

The repository currently has no deterministic mutation engine, while active review materials describe inferential mutation fallbacks. Reproducible execution is needed before mutation results can be treated as evidence. The staged changes extend the checked-in Stryker workflow with a focused executable path and explicit empty-target handling.

## What Changes

- Add `npm run test:mutation:smoke`, an executable focused Stryker runner.
- Add a small mutation target, its tests, and an isolated Stryker configuration that exercises real mutations.
- Validate that the engine produces mutations, kills at least one mutation, preserves native statuses, and cleans temporary output without polluting repository-local paths.
- Document the repository’s Stryker workflow and focused smoke command.
- Add an explicit Pass 11 outcome for runs with no eligible mutation targets.
- Extend review contract tests for deterministic execution, isolation, native outcomes, and absence of inferential mutation terminology.
