## Why

Unproven third-party integrations can make a full change expensive and risky before the required technical approach is known. A disposable implementer-only viability POC validates the blocking integration risk before feature specifications are emitted.

## What Changes

- Adds a third, technical-uncertainty axis to the pre-crystallization assessment after size and integration-point friction.
- Pauses feature crystallization when an unused third party and insufficient integration documentation create the same technical risk.
- Adds an explicit Ask 1 choice for creating a viability POC or proceeding with the full change at the accepted technical risk.
- Runs the POC through the Direct Build `--no-specs` profile, limited to implementation and the functional fix loop; it does not create OpenSpec artifacts, backfill drafts, archive a change, or run mutating Git commands.
- Presents explicit viable and not-viable post-POC menus, keeps the POC outside the feature slice set, and re-runs size and friction assessment after a viable POC when crystallization continues.
- Preserves the existing closure-state lifecycle, delegated-write boundaries, and fast-track gates; `--fast-track` does not auto-approve Ask 1 or post-POC menus.

## Capabilities

### New Capabilities

- `explore-technical-uncertainty-assessment` — Assesses unused third-party and insufficient-documentation risk before crystallization.
- `explore-viability-poc-pause` — Pauses emission for Ask 1 and routes viable or not-viable POC outcomes through explicit menus.
- `explore-direct-build-no-specs` — Provides the implementer-only Direct Build profile for a disposable viability POC.

### Modified Capabilities

- `explore-vertical-slicing` — Adds the third uncertainty axis, uncertainty routing, and the rule that a POC is not a feature slice.
- `explore-refactor-first-slicing` — Re-evaluates size and friction after a viable POC and preserves slice numbering.
- `explore-crystallization-on-demand` — Makes the uncertainty pause precede feature-block emission.
- `explore-pre-crystallization-stages` — Adds the uncertainty pause to the stage-4 sequence.
- `explore-closure-state` — Defines viable and not-viable POC exits without adding a fourth state.
- `explore-context-isolation` — Adds the explicitly authorized implementer-only POC write exception.
- `sai-fast-track-flag` — Keeps Ask 1 and post-POC menus interactive under fast-track.
