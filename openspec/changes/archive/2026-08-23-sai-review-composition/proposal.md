## Why

Today the `/sai-5-review` triage is informational: after reading the Recommended Audits block, users must manually launch each recommended audit (`/sai-6-security`, `/sai-7-performance`, `/sai-8-accessibility`) in separate sessions. This change automates the review→audit fan-out into one deterministic command — `/sai-review` — that runs the code-review phase to completion, parses the three surface-triage sections of the freshly regenerated `review.md`, and concurrently dispatches only the recommended audits as chained segments of a single supervising invocation, preserving per-phase worker ownership and closed lifecycle contracts.

## What Changes

- Adds a new user-invoked routed composition command `/sai-review` (not an `opsx:*` skill) with thin wrappers for both harnesses: `commands/claude/sai-review.md` (opus, low effort) and `commands/opencode/sai-review.md` (`opencode-go/deepseek-v4-flash`, variant `max`), both forwarding the `meta-review` invocation envelope.
- Adds the meta-review composition card set: `sai/commands/meta-review/command-bootstrap.md` (segment list + bounded triage parse) and `sai/commands/meta-review/coordinator.md` (supervising composition coordinator).
- Registers `meta-review` as a routed card name in both harness boot adapters (`sai/adapters/claude/boot.md`, `sai/adapters/opencode/boot.md`).
- Relaxes the shared composition rule in `sai/orchestration/command-runner.md`: the blanket prohibition on inferring the next phase from worker summary text, artifact contents, or `changed_files` text is removed; the no-skip-ahead rule is retained, and a composition may activate its declared consecutive successor under a declared conditional-activation rule.
- Documents the command in `AGENTS.md` (pipeline description, repo structure, Meta-review coordinator section, change-picker now twelve commands, two composition commands) and `README.md` (review command rows, artifact table row, shortcut table row, fast-track note, model table row).
- The composition strips an explicit `--fast-track` token as a behavioral no-op (not a sixth fast-track mode) and owns no questions of its own.
