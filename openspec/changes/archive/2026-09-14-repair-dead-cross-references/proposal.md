## Why

Agents follow cross-references and citations throughout their work. When a citation points to a file that no longer exists, or when the cited line no longer contains the claimed content, the agent receives incorrect or stale information. Repairing dead and drifted citations ensures that every citation used during agent work leads to accurate, current, or historically pinned content.

## What Changes

Citation repairs across normative instructions, capability specs, code comments, and decision records:

- **Normative instructions and policies**: Repointed explore item-10 citations in artifact-feedback-gate.md, question-context.md, and command-bootstrap.md to the step files that define or own the behavior.
- **Instruction line citations**: Updated implement.md references to point to where the testability rule currently resides; updated plan-generation.md to match.
- **Code comments**: Updated the derivation comment in apply-standalone.js (line 83) to reference the policy that states the equivalent derivation (sai/policies/todo-structure.md:27-32).
- **Main capability specs**: Repointed citations in dispatch-safety-invariant, empty-capability-directory-cleanup, progress-minimum-threshold, question-context-policy, and sai-backfill-completion-handoff specs to current file paths.
- **Decision records (ADRs/DDRs)**: Pinned 25 dead or drifted citations with commit SHAs where the cited lines contained the claimed content; reworded DDR 0114's reference to the never-committed GLOSSARY.md draft to preserve historical accuracy without a false pin.

## Capabilities

### New Capabilities

- normative-instruction-citations — Explore item-10 and implement testability-rule citations resolve to the files and lines that define or own the behavior.
- normative-capability-spec-citations — Main capability spec citations resolve to existing files and current line numbers, or name stable anchors instead of fragile line numbers.
- code-comment-citations — Code comments citing derivation rules reference the policy that states the equivalent derivation.
