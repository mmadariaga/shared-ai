## Why
Integration and E2E tests can make repeated GREEN runs prohibitively slow. This change keeps Step feedback scoped to the current Step RED tests while preserving a final regression gate before functional review.

## What Changes
- Defines one exact step-test-command per RED block selecting only that Step RED-authored tests, and one plan-level full-suite-command for terminal use.
- Passes the RED command unchanged from RED to GREEN, including paths, selectors, and arguments, without passing test contents.
- Scopes RED, GREEN, and coordinator Step verification to current-Step Automated checks, excluding the full repository suite and Functional checks from every Step gate.
- Runs the full repository suite once after the last Step commit and before terminal functional review, with functional review starting only after the suite passes.
- Updates apply contracts for coordinator dispatch, RED verification, GREEN verification, runner advancement, routing files, and terminal lifecycle, plus implement planning contracts for the plan template, generation scope, and validation.
- Adds a regression test covering the per-Step command assignment, the RED-to-GREEN handoff, the Automated-only Step gate, and the terminal suite ordering.

## Capabilities
### New Capabilities
- apply-step-verification: scope GREEN to the current Step RED tests and defer the full suite to terminal verification.

### Modified Capabilities
- None
