## Why
Fresh `node bin/install` keeps stale pre-retune models so installed globals diverge from `sai/install-manifest.json` while `doctor` still reports `compatible`. The global install preserved destination tunables via `spliceTunables` and `doctor` stripped tunable lines before comparing, freezing pre-retune values in place.

## What Changes
- `bin/install-flow.js`: `tunableSeedInstaller` overwrites the global destination with source bytes verbatim, comparing exact bytes to decide overwritten versus reused and emitting a notice naming the destination on any difference.
- `bin/doctor.js`: `managedBytesMatch` compares source and destination bytes exactly, dropping the tunable-keys parameter and `stripTunableLines`, so model-only drift reports as error for Claude and opencode workers.
- `test/agent-install-diagnostics.test.js`, `test/agent-projection-strategy.test.js`, `test/agent-tunable-ownership.test.js`, `test/implementation-harness-bindings-step-3.test.js`, `test/install-claude.test.js`: updated to the overwrite-on-global contract, asserting source models overwrite tuned values and doctor flags tunable-only drift.
