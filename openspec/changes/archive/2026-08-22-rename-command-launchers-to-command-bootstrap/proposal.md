> **⚠ POST-HOC RECORD** — This proposal was backfilled after implementation against a user-supplied statement of intent. It describes a decision already made, not one being proposed.

## Why

The `launcher.md` name was ambiguous, and empty command cards made agents incorrectly stop instead of continuing with the card selected by the harness boot adapter. The implementation renames the per-command cards and makes the empty-card handoff explicit.

## What Changes

The implementation replaces active per-command `launcher.md` cards with `command-bootstrap.md` cards across the 16 in-scope command directories. Intentionally empty bootstraps now state that they are not missing and that execution continues with the boot-selected card. Claude Code and opencode wrappers, active contract references, indexes, documentation, tests, and installation inventory expectations use the new name while preserving harness parity. The build and routed command bootstraps retain their existing non-empty binding loads.

The selected diff also updates active specification text in several files but leaves the reported terminology conflicts in other active specifications untouched, as required by this backfill scope. Historical archived documents and unrelated CLI or historical launcher terminology remain unchanged.

## Capabilities

### New Capabilities

- `command-bootstrap-handoff`: Empty command bootstraps explicitly hand execution back to the harness-selected card.

### Modified Capabilities

- `command-bootstrap-card`: The per-command card name changes from `launcher.md` to `command-bootstrap.md`.
- `command-bootstrap-wrapper-paths`: Both harness wrapper families fetch the renamed command bootstrap while preserving the invocation envelope.
- `command-bootstrap-projection-and-verification`: Installation projections, indexes, active contract references, and tests recognize the renamed cards and preserve Claude/opencode parity.

## Impact

- Renamed and added cards under `sai/commands/{name}/`, with old `launcher.md` cards removed.
- Updated Claude Code and opencode command wrappers, active specifications, `AGENTS.md`, `README.md`, `GLOSSARY.md`, and `SAI_LEARNINGS.md`.
- Updated command-card, coordinator, doctor, installation, layout, and wrapper tests for the new card name and empty-bootstrap handoff.
- External installed copies require projection/install refresh.
- Historical archived documents retain old terminology.
- Out of scope: `design.md`, `tasks.md`, `implementation.md` — not generated by /sai-backfill
