## Why

The previous manual archive path could fail through model execution, timeouts, or permission handling and leave synchronization and archiving incomplete. The installed OpenSpec CLI now provides deterministic scenario validation and couples synchronization with the archive move while SAI retains its preflight, gate, ownership, and commit safeguards.

## What Changes

- The normal `sai-archive` coordinator now invokes exactly `openspec archive <name> --yes --json` as the sole synchronization-and-move primitive after the existing gates.
- Direct Build archive execution delegates the same CLI invocation to the validated archive-worker execute continuation before exact-path staging and the pre-authorized local commit.
- Archive preflight retains classification, completion scanning, informational delta comparison, collision detection, fast-track unchecked-item behavior, and exact failure and terminal semantics.
- The separate delta-spec synchronization gate, manual synchronization procedure, and post-sync verification continuation are removed.
- CLI JSON results are authoritative; CLI failures or invalid JSON stop without manual fallback, staging, retry, or commit. Exact changed paths continue to come from preflight inventory and the invocation union.
- Documentation and structural contract tests describe the CLI ownership and preserve Claude Code/opencode parity.
