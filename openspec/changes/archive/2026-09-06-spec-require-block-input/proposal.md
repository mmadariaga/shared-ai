## Why

With explore owning maturation, spec's open questions are redundant. Spec becomes a normative translation of the crystallized block on creation, and its change-picker fallback plus Manual name-only path are retired for creation.

## What Changes

- `sai/commands/spec/worker.md` — creation and refinement are distinct entries. Creation requires the crystallized block concepts judged by concepts never byte-exact, resolves the name from the block Change name concept, and otherwise STOPs before resolution with a redirect to sai-explore. Refinement on existing artifacts needs only a simple prompt. The picker fallback and name-only creation path are removed.
- `sai/commands/spec/steps/common.md` — the four moved maturation bullets are deleted from Collaboration style and replaced with the explore-owns-maturation rule plus the retained normative-gap question channel.
- `sai/commands/explore/steps/pipeline-selector.md` — all three Manual-adjacent wordings are reworded from the name-suffixed example to the block-paste form, and the preserved-English literal list drops the name-suffixed literal.
