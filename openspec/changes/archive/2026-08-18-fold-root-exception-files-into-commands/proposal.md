> **⚠ POST-HOC RECORD** — This proposal was backfilled after implementation. It describes a decision already made, not one being proposed.

## Why

The prior layout treated three files as root exceptions even though each was consumed by exactly one command. That classification required redundant manifest projections and preserved obsolete path vocabulary. The implementation establishes command ownership as the source of truth while retaining hash-gated cleanup for former installed paths.

## What Changes

- Move `change-overview.md` to `sai/commands/design/`.
- Move the ADR and DDR index templates to `sai/commands/implement/`.
- Remove the three dedicated manifest projections and rely on the recursive `sai-commands` projection for both Claude Code and opencode.
- Add hash-gated retirement records for the former root destinations.
- Update implementation instructions, schema references, documentation, indexes, and installer tests to use the command-owned paths.
- Preserve modified or unrecognized legacy installed copies, leaving historical references to retired root-exception vocabulary as known documentation debt.

## Capabilities

### New Capabilities

- Command-owned source layout for the design overview instruction and ADR/DDR index templates.
- Recursive installation coverage for the moved command-owned files across both supported harnesses.
- Hash-gated retirement of the former root destinations.

### Modified Capabilities

- Implementation cold-build index maintenance reads ADR/DDR templates from the implement command directory.

## Impact

- Source files: `sai/commands/design/change-overview.md`, `sai/commands/implement/adr-index.template.md`, and `sai/commands/implement/ddr-index.template.md`.
- Installer metadata: `sai/install-manifest.json`, including three retirement records.
- Documentation and contracts: `AGENTS.md`, `README.md`, `INSTALL.claude.md`, `INSTALL.opencode.md`, `SAI_LEARNINGS.md`, `sai/SAI_AGENTS.md`, `sai/commands/implement/instructions.md`, and the workflow overview template.
- Verification: installer, source-layout, overview-contract, template-parity, and retirement tests.
- Historical limitation: modified or unrecognized former root copies remain inert, and some archival references retain retired root-exception terminology.
- Out of scope: design.md, tasks.md, implementation.md — not generated by /sai-backfill
