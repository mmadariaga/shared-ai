**Complexity**: medium

## Why
Claude Haiku 5.5 supports adjustable effort, but the Claude Code model customizer presented `haiku` without an effort selector. The implementation now offers the five supported effort values while preserving existing model-only Haiku settings and leaving the OpenCode customizer unchanged.

## What Changes
- Add `low`, `medium`, `high`, `xhigh`, and `max` effort choices to the Claude Code `haiku` catalog entry.
- Keep model-only `{ model: 'haiku' }` settings in a separate legacy-accepted configuration path for loading and factory reset.
- Validate new selections as concrete model-effort pairs without rewriting legacy or factory model-only settings.
- Update Claude Code selector, preset-loading, materialization, and reset coverage while leaving OpenCode behavior unchanged.

## Capabilities

### New Capabilities
No new capability is introduced.

### Modified Capabilities
- `model-customization-menu`: Claude Code Haiku selections now require one of five explicit effort values while generic injected model-only entries and legacy Haiku settings remain supported.
- `claude-budget-agent-tunables`: Claude Haiku overrides for budget agents persist explicit effort values without changing the global seed, while legacy model-only settings remain valid.
