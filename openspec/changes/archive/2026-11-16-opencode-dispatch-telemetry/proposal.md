## Why

The motivation of opencode routing is cost per worker. A worker that a Claude Code run dispatches through `opencode-dispatch.js` runs as an `opencode run` session, which `opencode.db` stores as an unlinked root session, and Claude Code leaves no `subagents/agent-<id>.meta.json` file for it. Change telemetry and the retrospective therefore could not see the tokens such a worker spent: subagent discovery in `sai/tools/claude-transcripts.js` found only Claude Code subagents.

## What Changes

- `sai/tools/claude-transcripts.js` adds `dispatchedWorkers`, which finds the `opencode-dispatch.js start|continue` shell calls in a Claude Code transcript and takes each worker's `sessionID` from the JSON result the dispatch tool printed: the result of the call itself, the output file of its background task (named by the call result or by the task notification), or a later call that read that file. A `continue` names its session on its own command line, so one worker is one session however many calls continue it. A `start` whose `sessionID` cannot be found is a worker with no session.
- `openClaudeSource` lists the opencode-routed workers of a root session and of each of its subagents as children of the dispatching session, with the opencode `sessionID` as their ID, and reads their requests from `opencode.db`, opened read-only on first use through `opencode-db.js`.
- `sai/tools/opencode-db.js` adds `opencodeSessionMessages`, which returns the assistant messages of one session in order, or `null` when the session is not recorded.
- `sai/tools/change-telemetry.js` gives each opencode-routed worker of a Claude Code run an agent row of its own. Its cost is the one the provider recorded when it is above zero; a recorded 0 is no price, so the cost is unavailable and the Claude price table never estimates it. A worker whose session cannot be read is an `unavailable (<agent>: <reason>)` row, never a zero row.
- `sai/tools/retrospective.js` adds the opencode-routed workers of the root session and of its principal workers to the execution index, with `usage` and `tool_calls` read from `opencode.db` by `sessionID`, a principal routed worker's records scanned for loaded instructions and tool errors, and a recorded currency cost of 0 dropped from the figures. A routed worker whose session cannot be read has `usage: unavailable` and an `unread` entry of kind `opencode-routed-worker` that names the agent, the opencode session, and the reason.
- `AGENTS.md` describes the opencode-routed workers in the `sai/tools/retrospective.js` row.
- Tests cover the routed rows of change telemetry and of the retrospective cost report and the unavailable cases.

## Capabilities

### New Capabilities

None

### Modified Capabilities

- `change-telemetry`: a Claude Code run's telemetry attributes to each opencode-routed worker the tokens of its opencode session, and reports an unreadable session as unavailable.
- `sai-retrospective`: the Claude Code execution index and cost report carry the usage of each opencode-routed worker, and report an unreadable session as unavailable and unread.

## Impact

- Modified: `sai/tools/claude-transcripts.js`, `sai/tools/change-telemetry.js`, `sai/tools/opencode-db.js`, `sai/tools/retrospective.js`, `AGENTS.md`, `test/change-telemetry.test.js`, `test/retrospective-tool.test.js`.
- Reads of `opencode.db` stay read-only.
- Currency cost stays unavailable for models whose provider reports no price.
