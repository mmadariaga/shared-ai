> **⚠ POST-HOC RECORD** — This proposal was backfilled after implementation. It describes a decision already made, not one being proposed.

## Why

The SAI command wrappers and Copilot budget-subagent agent contained outdated model identifiers. The implemented changes update those identifiers and the affected Claude effort tiers to current model assignments.

## What Changes

- Update Claude SAI wrapper model metadata for specification, implementation, apply, review, security, performance, accessibility, archive, backfill, commit, explore, PR, and status commands.
- Set explicit Claude effort metadata where the affected wrappers require it.
- Update Copilot SAI prompt model metadata for spec, implementation, apply, security, backfill, and explore commands.
- Update the Copilot budget-subagent agent model from GPT-5 mini to GPT-5.6 Luna.

## Capabilities

### New Capabilities

None. The changes update model-routing metadata for existing commands and agents.

### Modified Capabilities

- `claude-model-routing`: Updates the model and effort metadata used by Claude SAI command wrappers.
- `copilot-model-routing`: Updates the model metadata used by Copilot SAI prompt wrappers.
- `copilot-budget-subagent-model`: Updates the Copilot budget-subagent model identifier.
