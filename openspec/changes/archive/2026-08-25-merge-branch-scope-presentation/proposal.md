**Complexity**: low

## Why

Prevent already-contained branches from being offered as merge candidates, provide precise date-and-time context for branch recency, and make the broadest recommended conflict scope immediately visible.

## What Changes

- Merge branch discovery now uses `git branch --no-merged HEAD`, retaining only local branches with commits not already reachable from the current branch.
- Branch option values remain exact branch names, while labels include the last-commit timestamp as `YYYY-MM-DD HH:mm`.
- Conflict scope options place `Full scope (Recommended)` first, followed only by applicable category-specific scopes.
- Merge instructions, the worker contract, the presentation seam, and focused contract tests describe and verify the same behavior.
- Existing no-eligible-branch behavior remains unchanged.
