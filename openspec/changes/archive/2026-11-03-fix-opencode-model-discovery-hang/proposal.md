## Why

Synchronous discovery could freeze OpenCode customization and prevent cancellation. Asynchronous execution keeps controls responsive without requiring an open interface.

## What Changes

- Bound model and variant queries to 30 seconds, excluding user choice time.
- Support Escape back and q/Ctrl+C cancel, restore keyboard controls, and ignore late responses.
- Bound owned-process cleanup to one second and report uncertain termination.
- Recover to the menu without writes and retain targets for explicit retry; preserve Claude Code behavior and successful persistence authorization.

## Capabilities

### New Capabilities

None.

### Modified Capabilities

- opencode-model-discovery: asynchronous bounded queries and cleanup.
- opencode-variant-discovery: independent query deadline.
- opencode-settings-selection: wait controls and restoration.
- model-customization-menu: no-write recovery with retained retry targets.
