## Why
Review artifacts relied on each phase worker's own self-critique, so weak or speculative findings survived into review.md, security.md, performance.md, and accessibility.md with inflated severity. A bounded pre-save adversarial filter discards false positives and corrects severity while leaving the worker with the last word.

## What Changes
Added a per-phase Adversarial Findings Check hook between the in-memory draft and the save in four close-outcome steps: sai/commands/review/steps/close-review-outcome.md, sai/commands/security/steps/close-security-outcome.md, sai/commands/performance/steps/close-performance-outcome.md, and sai/commands/accessibility/steps/close-accessibility-outcome.md. Each hook dispatches exactly one cheap-tier budget-explorer subagent with only the in-memory findings list, reads from disk on demand without a packaged diff, enforces per-finding evidence minima and a what-and-why verdict report, lets the worker accept or reject each verdict, recomputes the Summary tally over kept findings at final severity, skips on zero findings, and never blocks on subagent failure.
