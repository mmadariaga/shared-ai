## Why

`/budget` is only a convenience wrapper and is not used by the SAI pipeline. Removing it keeps the command inventory focused without affecting internal budget behavior.

## What Changes

- Delete the Claude Code and opencode `/budget` command wrappers.
- Remove `/budget` from the universal command registry.
- Update launcher, installation, and model-customization tests to assert the 19-command inventory and absence of the budget wrapper.
- Preserve the existing recursive command projection, budget skills, generic delegation agents, and internal budget dispatch behavior.
