## Why
The opencode examples shipped without a Claude counterpart, so Claude users get no documented starting point and a fresh install seeds nothing for them. Mirroring the same copy-if-absent pattern closes that gap without touching opencode surfaces or Save/Load flows.

## What Changes
- Add sai/presets/claude/OPUS.json, the single Claude example preset mapping coordinators, workers, and budget helpers to opus, sonnet, and haiku with effort levels.
- Add the claude-preset-examples copy-if-absent projection in sai/install-manifest.json projecting sai/presets/claude to the Claude sai presets library with the harness segment stripped, recursive JSON include, and managed content drift.
- Extend README.md Post Install with the Claude copy-if-absent paragraph, one OPUS.json row in the Example presets table with Claude-only use-when guidance, and the Claude Code Load preset line naming OPUS without .json.
- Update test/doctor-harness-inventory.test.js, test/install-claude.test.js, and test/install-opencode.test.js to expect OPUS.json in the Claude-only sources.
- Reuse the existing copy-if-absent doctor warn and uninstall override-guard branches for the Claude example with no doctor or uninstall code change; an existing destination preset stays intact with no merge, overwrite, or content validation.
