## Why

OpenCode v2.0.18 was observed to run a subagent configured with `model#variant` using the orchestrator's model. A bare model selected the intended subagent model. The effect of the variant at runtime was not independently visible.

## What Changes

- The three shipped OpenCode generic agents declare a bare `model` and a separate `variant: xhigh`.
- The OpenCode worker template and matrix render the existing worker models and variant levels as separate fields; Claude Code worker generation remains unchanged.
- Agent customization reads earlier combined `model#variant` values and writes a bare model with an optional separate variant. A selection without a variant removes an existing variant line. OpenCode command customization retains its combined format.
- A global installation does not change project-local `.opencode/agents/` definitions; customization changes only a selected local agent.
- README.md and AGENTS.md describe the distinct agent and command formats, and tests cover generation, customization, and local-file preservation.

## Capabilities

### New Capabilities

None.

### Modified Capabilities

- `opencode-agent-model`: OpenCode generic and generated worker agents use separate model and variant fields.
- `model-customizer`: Selected OpenCode agent overrides accept older combined input and write the separate format without changing command customization.
- `opencode-defaults-alignment`: The shipped agent defaults retain their models and variant levels in separate fields.
- `project-local-agent-overrides`: A selected older override can be rewritten; installation leaves project-local definitions untouched.
