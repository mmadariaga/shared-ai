## Why

This fixes the model selector bug on Windows, where the OpenCode npm command shim could not be launched safely with its arguments. It also makes command-launch and non-zero-exit failures visible instead of ending silently. The interview identified no known limitations or remaining technical debt.

## What Changes

- Update `bin/agent-customization.js` so the default command runner resolves Windows npm shims through PowerShell while transporting the executable and argument array as JSON environment data.
- Preserve direct argument-vector execution on non-Windows platforms and expose the runner for testing.
- Return stderr and throw launch errors from the runner so catalog and verbose model discovery can report actionable diagnostics before cancelling.
- Add tests covering Windows argument transport, non-Windows execution, and catalog launch-failure reporting.

## Capabilities

### New Capabilities

None. The implementation modifies existing model-discovery capabilities.

### Modified Capabilities

- `opencode-model-discovery`: Windows catalog discovery now resolves the npm shim safely and reports launch or non-zero-exit failures before non-fatal cancellation.
- `opencode-variant-discovery`: Windows provider-scoped verbose discovery now uses the same safe argument transport and reports command failures before cancellation.
