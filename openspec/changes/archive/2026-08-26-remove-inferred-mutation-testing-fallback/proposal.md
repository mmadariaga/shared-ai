## Why

Current active review materials authorized model-selected mutations when no deterministic tool was declared, making inferred outcomes appear to be execution evidence. The implementation replaces that fallback with deterministic tooling and explicit operational-state reporting.

## What Changes

- Adds Stryker as the declared deterministic mutation engine with a reproducible `test:mutation` command and checked-in configuration.
- Restricts mutation execution to explicitly supplied eligible production files.
- Reports unavailable tools, baseline failures, execution failures, and report-parse failures without producing mutation findings.
- Preserves engine-native mutation statuses and maps only `Survived`, `Timeout`, and `NoCoverage` to High findings.
- Removes active review-worker, instruction, template, README, and test references to inferred mutation execution.
- Ignores generated mutation temporary files and reports.

## Capabilities

### New Capabilities

None. This change modifies the existing mutation-analysis capability.

### Modified Capabilities

- `mutation-analysis`: Review mutation analysis now uses deterministic engine execution and explicit failure reporting without inferred results.

## Impact

- `.gitignore`: ignores Stryker temporary files and mutation reports.
- `README.md`: documents deterministic mutation analysis and unavailable-tool behavior.
- `package.json` and `package-lock.json`: declare and lock Stryker.
- `stryker.config.js`: defines the reproducible test runner, scope, reporters, timeout, concurrency, and cleanup behavior.
- `sai/commands/review/instructions.md`: removes the inferential mutation protocol.
- `sai/commands/review/review-report.template.md`: defines deterministic status aggregation and reporting.
- `sai/commands/review/steps/resolve-mutation-analysis.md`: defines deterministic execution and failure handling.
- `sai/commands/review/steps/resolve-review-analysis.md` and `sai/commands/review/worker.md`: preserve routed-contract parity.
- `test/review-coordinator-worker.test.js`: verifies configuration and absence of inferential fallback wording.
- Out of scope: design.md, tasks.md, implementation.md — not generated by /sai-backfill
