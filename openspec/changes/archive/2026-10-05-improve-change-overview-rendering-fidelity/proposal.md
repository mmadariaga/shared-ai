> **⚠ POST-HOC RECORD** — This proposal was backfilled after implementation against a user-supplied statement of intent. It describes a decision already made, not one being proposed.

## Why

A regenerated Change Overview mixed English and Spanish headings and omitted selected source content. Bare Files Affected entries also risked merging when rendered as Markdown and hiding technical literals such as `<timestamp>`. The shared generation instruction previously allowed source headings and Step titles to translate, and its formatting-preservation rule did not explicitly permit a readable file-entry wrapper.

The implemented changes establish consistent English navigation, literal file-entry presentation, and source-unit completeness checks before accepting a generated or regenerated overview.

## What Changes

- Keep every actual Markdown heading, complete Step title, and structural field label English regardless of the selected explanatory-prose language.
- Translate only explanatory prose. Preserve technical literals and heading-like text inside code.
- Require complete transfer of selected paragraphs, list items, table rows, references, identifiers, test assertions, and field content.
- Render each Step's Files Affected entries in one fenced text block, preserving literal content, whitespace, order, repetitions, deletions, and renames. Reuse an existing single block and normalize other block wrappers without nesting or duplication.
- Explicitly permit only heading-depth adjustment and Files Affected wrapping as formatting exceptions.
- Reject incomplete or incorrectly rendered candidates with `validation-failed`; retain `blocking-contradiction` for conflicting sources.
- Align the overview template with the literal file-entry presentation.
- Update both overview contract test files to enforce English headings and labels. Add assertions for file blocks, timestamp paths, complete source-unit validation, and failure classification.

Existing source selection, Step joins, invocation-language transport, generation conditions, single-file generator scope, and transactional acceptance remain unchanged.

- `change-overview-artifact`: Literal per-Step file-entry blocks and explicit selected-unit fidelity checks for generation and regeneration.

English headings remain a deliberate localization boundary; file-entry wrapping remains a deliberate formatting exception.
