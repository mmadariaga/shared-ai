**Complexity**: medium (10 files, shared policy and route updates)

## Why

SAI mutation instructions assumed a Bash-named command tool and Bash heredoc transport, so Direct Build archive and authorized commit paths could fail when the available command tool ran PowerShell 7. The implementation defines a shared portable execution contract and updates each affected mutation point while preserving authorization, ordering, and path-safety rules.

## What Changes

- Add `sai/policies/command-execution.md` as the shared contract for Bash and PowerShell 7 command invocation and literal standard-input message delivery.
- Use the active supported command-execution tool without requiring a tool displayed as `Bash`, while preserving argument boundaries, operation order, authorization, output, and exit status.
- Deliver commit messages literally over standard input, including multiline, Unicode, quote, dollar-sign, backtick, apostrophe, and final-line-feed cases.
- Update ordinary archive, Direct Build archive, `/sai-commit`, `/sai-merge`, Explore Direct Build close, and meta-review Direct Build close mutation instructions to load and use the shared policy.
- Pass the ordinary archive pushed-HEAD reference as one quoted Git argument.
- Add Bash and PowerShell 7 transport and failure-propagation tests.

## Capabilities

### New Capabilities

- **portable-command-invocation** — Provides one shared Bash and PowerShell 7 command-execution and literal-message-delivery contract for mutation surfaces.

### Modified Capabilities

- **auto-fast-archive-execution** — Preserves Direct Build archive order, safeguards, exact-path staging, and one-commit authorization while allowing Bash or PowerShell 7 execution.
- **sai-archive-commit-gate** — Preserves archive commit gates and passes the pushed-HEAD reference safely as one Git argument.
- **commit-apply** — Keeps commit.js standard-input behavior while removing the coordinator's mandatory Bash heredoc transport.
- **sai-merge-command** — Keeps coordinator-owned authorized commits while delivering informative merge messages through standard input without Bash-only syntax.
