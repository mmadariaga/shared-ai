## Why

The existing Auto option on sai-explore's crystallization-close pipeline selector stops at planning artifacts ("sai-3 was not run"), so simple changes still paid the full spec → design ceremony across separate sessions before any code was written. This change adds a fast lane that takes a crystallized idea to an implemented, archived, and committed change in one unattended session: a dedicated implementer worker executes directly from the crystallized block, explore functionally reviews and fix-loops the resulting diff, backfill reconstructs the workflow artifacts retroactively, and a hands worker performs the validated writes plus archive mutations and the pre-authorized local commit.

## What Changes

- sai-explore's crystallization-close selector now carries exactly three options — Auto, Auto (fast implementation), Manual — each with a fixed one-line description; selecting the new option consents delegated writes AND pre-authorizes exactly one local commit.
- Item 1's no-file-writes rule gains an explicit scoped exception authorizing the two fast-lane workers' writes; item 10's supervised no-implementation invariant gains an explicit scoped exception naming the fast lane as the sole consented exception.
- A new **Auto (fast implementation) supervision contract** defines the seven-step unattended flow: block-driven implementer dispatch (α input model), functional fix loop under three-round budget semantics, sibling backfill reconstruction from staged changes over a captured base SHA, read-only schema validation plus one review continuation, the ADR/DDR criteria pass, archive segment under fast-track gate semantics, and closed-order validated mutations ending in the pre-authorized HEREDOC local commit.
- Two new explore-owned budget-tier worker contracts: `sai/commands/explore/autofast-implement-worker.md` and `sai/commands/explore/autofast-hands-worker.md`.
- The Worker Matrix gains two closed role entries (`autofast-implement`, `autofast-hands`) pinned to their explore-owned contracts; installer roster validation moves from twelve to fourteen workers for both harnesses.
- `sai/install-manifest.json` gains matrix entries and managed-agent projections for Claude Code and opencode; AGENTS.md documents the option. Sixteen test files were updated to assert the new behavior.
