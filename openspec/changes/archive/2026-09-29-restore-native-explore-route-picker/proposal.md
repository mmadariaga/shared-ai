**Complexity**: high

## Why

`/sai-explore` now presents a native route picker after it displays and records the complete `Ready to Propose` set. This preserves the existing protection against premature work while removing the unnecessary requirement to type a route name.

## What Changes

- `explore-slice@1` exposes the route-selector pointer after successful ordered inventory recording while retaining `blockEmissionTurnClosed` until a valid picker answer arrives.
- The route selector presents exactly three native options in order: `Plan - Unattended`, `Direct Build - Unattended`, and `Manual`.
- Claude Code uses `AskUserQuestion`; opencode uses the `question` tool. Only an exact returned picker label selects a route.
- Cancelled, absent, free-text, ambiguous, or multi-route answers preserve the waiting inventory and start no route.
- Plan and Direct Build use the first pending crystallized slice, while the separate Direct Build continuation question remains independent.
- Route prose and picker descriptions follow the crystallization language choice while fixed route titles and command literals remain unchanged.
- Explore instructions, route contracts, ready-block guidance, state-machine behavior, panel ownership, and focused tests now share the native-picker contract across both harnesses.

## Capabilities

### New Capabilities

None.

### Modified Capabilities

- `explore-route-choice`: Present the native three-route picker after inventory recording and retain explicit-answer route authorization.
- `explore-crystallization-block`: Follow the successful ordered-inventory pointer to route-picker presentation without starting work.
- `deferred-selector`: Replace the mandatory later typed route reply with the native picker while retaining the explicit decision gate.
- `crystallization-close`: Permit same-turn picker presentation after the close checkpoint while deferring route activation until the later answer.
- `explore-slice-machine`: Expose the selector pointer from recorded inventory while retaining the machine route-intent lock.
- `explore-pipeline-selector`: Preserve Plan, Direct Build, Manual, continuation, dispatch, and duplicate-start behavior under native picker selection.
- `explore-crystallization-language-gate`: Localize picker context and descriptions while preserving English route titles, literals, and language-gate behavior.
