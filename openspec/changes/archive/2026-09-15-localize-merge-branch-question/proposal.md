## Why
The merge branch selector asked a fixed Spanish question in every project, which violates the ambient-language rule and looks odd in English projects. Branch selection happens before working_language is known, so the selector must render in the ambient conversation language like the conflict-language question does, while keeping branch values stable.

## What Changes
- Canonical English source Which branch do you want to merge? replaces the fixed Spanish literal in sai/commands/merge/instructions.md and sai/commands/merge/worker.md.
- Coordinator presentation seam in sai/commands/merge/presentation.md renders the concise wording in the ambient conversation language: Spanish keeps ¿Qué rama quieres mergear?, English uses the canonical, any other language falls back to the canonical.
- Option values stay exact local branch names; labels stay <branch> — last commit <YYYY-MM-DD HH:mm>.
- Adjacent gate summary keeps detailed current branch, candidate timestamps, and merge rationale in the ambient conversation language; selection still occurs before working_language and never opens the working-language question early.
- Scope limited to branch selector; scope, strategy, and authorization gates unchanged.
