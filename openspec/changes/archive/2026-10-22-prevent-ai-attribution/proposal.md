## Why

Existing commit-message checks did not enforce the AI-attribution rule, and PR/MR descriptions had no equivalent control. Conflicting written rules also obscured the explicit-user-request exception and unnecessarily excluded human coauthors.

## What Changes

- Added a shared line-numbered AI-credit detector for generated/authored/assisted credits and AI coauthor trailers, including model-family/version identities and known bot identities. Human coauthor credits remain allowed.
- Integrated default rejection into commit validation for new and amended sai-commit commits. The explicit-user-request exception uses --allow-attribution and leaves format, sensitive-file, and authorization checks intact.
- Validated the final to-pr description at query and publish for creation and updates. Only boolean allow_attribution: true enables the exception; existing title, publication, and push requirements remain.
- Aligned shared policies, repository guidance, and implement/review/build direct-commit instructions for Claude Code and opencode. Harness, tool, and system suggestions do not constitute a user request. Direct commits received written guidance only, not automatic validation.
- Added refusal-before-mutation, exception, human-credit, model-family/version, and safeguard regression coverage.
