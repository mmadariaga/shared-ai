## Why

The repository's documented Orchestration Core is the canonical set of `sai/orchestration/` contracts for coordinator mechanics and worker lifecycle behavior, but the neutral command-runner and worker-core contracts were stored at the `sai/` root. The implementation aligns the source layout with that documented definition.

## What Changes

- Move `sai/command-runner.md` to `sai/orchestration/command-runner.md`.
- Move `sai/worker-core.md` to `sai/orchestration/worker-core.md`.
- Update Claude Code and opencode boot adapters and routed command cards to fetch the relocated contracts.
- Re-project both contracts under `orchestration/` for both supported harnesses in `sai/install-manifest.json`.
- Add hash-gated retirement records for the former root destinations, preserving modified or unrecognized files.
- Update regression tests, AGENTS documentation, fetch-path references, and DDR documentation for the relocation.
