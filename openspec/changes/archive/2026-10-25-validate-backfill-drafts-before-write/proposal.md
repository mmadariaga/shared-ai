## Why
SAI accepted approved scenario-removal and rename exceptions that OpenSpec rejects, allowing drafts to pass preliminary checks and fail after repository materialization. Complete-set CLI validation now detects these incompatible forms before writes, using current specifications in an isolated temporary project.

## What Changes
- **BREAKING**: Retired MODIFIED scenario exceptions, the --scenario-exceptions flag, and temporary exception metadata. Existing scenario names remain mandatory; their content and order may change and new scenarios may be added.
- Supported intentional replacement uses a distinct, explicitly chosen non-colliding requirement name; no replacement name is silently invented.
- Added one shared complete-draft CLI validator for standalone backfill and Direct Build, copying current specifications, configuration, and schemas into a private temporary project without modifying the source project or registering a store.
- Bound successful validation to draft references and bytes plus current specifications, configuration, and schemas; receivers and Direct Build workers check freshness before writes.
- Kept independent preservation checks and archive CLI controls, including after corrections.
- Added real-CLI tests for scenario loss, replacement forms, complete copying, unavailable/incomplete validation, and input freshness.

## Capabilities
### New Capabilities
- pre-write-backfill-validation: Complete-set temporary-project CLI validation, diagnostic retention, failure safety, and accepted-input freshness.
### Modified Capabilities
- delta-header-preflight: Mandatory scenario preservation with retired exceptions and pre-write validation sequencing.
- delta-header-tool-paths: Retired exception flag from accepted checker invocations.
- routed-backfill-command: Independent author and receiver preservation checks plus complete CLI validation before final writes.
- backfill-draft-transport: Reference-only drafts, validation fingerprints in execution orders, and repeated correction checks without exception metadata.
- explore-pipeline-supervision: Complete-set receiver validation and freshness before Direct Build authorization.
- routed-archive-command: Independent current-delta preservation without exception metadata or approval bypass.
