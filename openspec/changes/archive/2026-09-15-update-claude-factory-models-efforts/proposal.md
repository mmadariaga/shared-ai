## Why
Current factory seeds overused haiku and low effort where stronger reasoning is required. The change standardizes Claude factory defaults on opus and sonnet with explicit catalog efforts, leaving haiku without an effort line.

## What Changes
- Update 14 Claude command wrappers in commands/claude to standardized opus/medium and sonnet/medium factory seeds, including the opus/xhigh to opus/medium normalization for the security command.
- Update 8 worker-matrix claudeAgent entries in sai/install-manifest.json from haiku/low and opus/high to opus/medium and sonnet/medium.
- Update 3 budget agent seeds in agents/claude, removing the effort line from the haiku executor and moving explorer and subagent to sonnet with catalog efforts.
- Apply short model names haiku, sonnet, and opus with no vendor prefix, omit effort for haiku, and require a catalog effort for opus and sonnet.

## Capabilities
### New Capabilities
- claude-command-seeds: standardized model and effort factory seeds for Claude command wrappers.
- claude-worker-seeds: standardized claudeAgent model and effort seeds in the worker matrix.
- claude-agent-seeds: standardized model and effort seeds for Claude budget agents.
### Modified Capabilities
- None. All three capabilities are new delta specs; no existing capability spec is modified by this change.
