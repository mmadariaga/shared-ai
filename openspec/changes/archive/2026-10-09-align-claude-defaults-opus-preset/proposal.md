## Why

The shipped Claude Code model and effort defaults differed from `sai/presets/claude/[sai-default]-OPUS.json`. The user selected that unchanged preset as the reference for both settings. The implementation aligns the shipped configuration with all 36 roles in that preset.

## What Changes

- Updated model and effort frontmatter in the Claude Code command wrappers whose defaults differed from the preset.
- Set all three Claude Code generic-agent seeds to haiku with explicit medium effort, including adding the previously absent executor effort.
- Updated the corresponding `claudeAgent` model and effort values in the managed-worker matrix, including model and effort reductions.
- Added regression coverage comparing canonical defaults and generated Claude Code projections with all 36 preset entries: 15 commands, 15 workers, 3 generic agents, and 3 utilities.
- Added a fixed hash check for the reference preset and a pre-alignment fingerprint check for generated opencode agents, command wrappers, and configuration.
- Updated existing tests that asserted the previous Claude Code defaults.

## Capabilities

### New Capabilities

- `claude-default-preset-alignment`: Regression verification of exact model and effort alignment across canonical and projected Claude Code roles, the unchanged reference preset, and unchanged generated opencode output.

### Modified Capabilities

- `claude-agent-seeds`: All three generic-agent defaults now use haiku with medium effort.
- `claude-command-seeds`: Command and utility defaults now reflect the selected preset rather than uniform historical role-group settings.
- `claude-worker-seeds`: Managed-worker Claude Code defaults now reflect each worker's model and effort in the selected preset.
