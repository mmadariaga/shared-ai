## Why
The previous change added per-layer CodeGraph notices but left the old generic hint emission in place in `bin/install-flow.js`, so install still printed `MCP wiring: run \`codegraph install\` if not already wired` whenever the `codegraph` binary existed, even with MCP and index fully configured. A fully-wired setup SHALL print no CodeGraph line at all.

## What Changes
Removed the leftover generic wiring-hint path from `bin/install-flow.js`: deleted the `CODEGRAPH_WIRING_HINT` constant, removed the `emitInstallerNotice(notices, CODEGRAPH_WIRING_HINT)` emission on the probe-pass branch of `offerCodegraphInstall()`, and removed the constant from `module.exports`. The layered `emitCodegraphStateNotices` remains the sole CodeGraph messaging path. Updated `test/install-codegraph.test.js` binary-present cases (TTY and no-TTY) to assert silent return (`messages.length === 0`) instead of asserting the wiring hint, and renamed them to `returns silently`.

## Capabilities
### New Capabilities
None — this change adds no new behavior; it removes the generic hint and silences the CLI-present branch.

### Modified Capabilities
- `installer-codegraph-cli-bootstrap`: CLI-present branch returns silently with no CodeGraph line; probe description no longer references the wiring hint.
- `actionable-notices-summary`: generic wiring hint removed from the deduplicated notices collection and from `emitInstallerNotice` routing; only per-layer recommendations remain.
