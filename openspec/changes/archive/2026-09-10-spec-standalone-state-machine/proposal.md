**Complexity**: medium (4 files, 2 new capabilities, no breaking change)

## Why

Standalone `sai-1-spec` preloads 1000+ lines up front (`worker-core`, `bounded-recovery`, gates), which confuses small/cheap models; relocating happy-path step routing into a stateful sidecar machine lets the startup stay minimal while the worker only ever sees its current step.

## What Changes

- `sai-state/machines/spec-standalone.js` (new, 171 lines) — stateful sidecar machine `spec-standalone@1` owning standalone happy-path routing; six-step stage table as-is with `follow: none` for `prereqs-and-change`; `transition` marks declared ids monotonic in canonical order and ignores undeclared ids silently with no notification; `project` re-resolves the active step from the surviving `done` set; `next.follow` is routing identity with loaded-set skip hints; terminal `done` maps to `follow: none`.
- `sai-state/registry.js` (modified, 1 line) — registers `spec-standalone@1` alongside `explore-idea@1` and `explore-slice@1` with no change to existing registrations.
- `sai/commands/spec/coordinator.md` (modified) — standalone-only integration consulting the sidecar per progress event and wrapping `next.follow` in the unchanged two-line continuation; wire stays byte-identical; fresh sidecar session per standalone run closed at run close; parked with no pointer on `needs_input`/`failed`/`cancelled`; replacement re-resolution; unknown follow target or path outside `steps/` stops with an error and fetches nothing; follow-load failure stops, shows the error, and waits, never via Bounded Recovery; loaded-set skip applies.
- `test/spec-standalone-machine.test.js` (new, 131 lines, scope drift, implemented) — verification for registration, E4 initial pointer, happy-path walk to `done`, E2 silent ignore, E3 replacement re-resolution, E7 parked empty signal, and purity with no input mutation.

Known limitations left behind: sidecar per-turn overhead (spawn, emit, session file) accepted for a single maintainable routing mechanism; no-whitelist follow limitation inherited from explore so a surprising machine-named path loads the same way; homogeneity ends at the standalone/supervised seam with the supervised adapter keeping its own routing-only map by explicit scope decision.

- `reactive-instruction-loading`: per-state follow files plus event-gated contracts with no heavy upfront preload.
