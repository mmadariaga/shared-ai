> **⚠ POST-HOC RECORD** — This proposal was backfilled after implementation against a user-supplied statement of intent. It describes a decision already made, not one being proposed.

## Why

Backfill drafts omitted or renamed existing scenarios, while the deterministic delta checker validated requirement headings only. The implemented checks detect accidental scenario loss before temporary drafts are accepted and again before published specifications are synchronized.

## What Changes

- Extend the shared delta checker to compare existing scenario names within each MODIFIED requirement, preserving requirement-header classification and allowing changed scenario order, text, and additional scenarios.
- Support exact temporary removal and rename exceptions; require independent coordinator approval against accepted scope instead of trusting a worker declaration.
- Report missing scenarios as concrete violations and unreadable or ambiguous comparisons as incomplete rather than successful.
- Require separate checks by the draft author, the receiving coordinator, and the archive coordinator, including corrected drafts.
- Carry temporary exception references separately from materializable drafts and retain Direct Build transfer state through archive and corrections.
- Add shared tool regressions and update backfill and archive usage documentation for Claude Code and opencode.

## Capabilities

### New Capabilities

- None.

### Modified Capabilities

- `delta-header-preflight`: scenario-name comparison, narrow exceptions, and failure reporting in the existing checker and pre-write check.
- `delta-header-tool-paths`: supported temporary exception flag without changing tool-resolution or project-root semantics.
- `routed-backfill-command`: author and receiver checks with independent approval before accepting draft writes.
- `routed-archive-command`: independent preservation checks immediately before synchronization and after content corrections.
- `explore-pipeline-supervision`: deterministic Direct Build completeness review that cannot accept failed comparisons through review-budget exhaustion.
- `backfill-draft-transport`: separate temporary exception references, correction verification, and retention through Direct Build archive.
