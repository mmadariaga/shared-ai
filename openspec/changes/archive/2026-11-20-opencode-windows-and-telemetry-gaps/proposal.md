## Why

The v0.12.0 milestone review found three gaps around opencode-routed workers (issue #486, F4, F6, F15). AGENTS.md said `bin/doctor.js` spawns the command `opencode-launcher.js` resolves, but on Windows doctor still ran `opencode` through a shell. Change telemetry and the retrospective read each opencode-routed worker of a Claude Code run but never the helper sessions that worker started, so they under-counted without saying so. Whether disposing an opencode-routed worker on Windows leaves `opencode run` running was unverified, because the signal handlers of `opencode-dispatch.js` do not run on Windows.

## What Changes

- `bin/doctor.js` (`defaultExecOpencode`) drops its Windows `shell: true` branch and spawns, without a shell, the command `opencode-launcher.js` resolves, as `opencode-dispatch.js` and `dispose-shells.js` do. A shim the launcher cannot resolve is not spawned: the version check reports `opencode-shim-unresolved` with the shim path as an unverified-version warning.
- `sai/tools/claude-transcripts.js` (`children`) walks the child sessions of each readable opencode-routed worker through `opencodeChildren` and lists them under the worker, so change telemetry gives each helper its own row. A child set that cannot be read is one `unavailable` row under the worker, never zero helpers.
- `sai/tools/retrospective.js` adds the same helpers to a Claude Code execution as auxiliary agents in the worker's segment, with the usage of their own sessions; an unreadable child set is an `unavailable` agent and an `unread` entry of kind `opencode-routed-helpers`.
- The header comment of `sai/tools/opencode-dispatch.js` records that its signal handlers do not run on Windows and that Claude Code's `TaskStop` on the `Bash` task ends the whole process tree there, as verified on Windows with a Node parent that spawned a child with the same options. The handlers stay, and the code is unchanged.

## Capabilities

### New Capabilities

None

### Modified Capabilities

- `opencode-agent-dispatch`: doctor uses the launcher; the verified Windows dispose behavior is recorded.
- `change-telemetry`: Claude Code telemetry counts the helpers of opencode-routed workers.
- `sai-retrospective`: the Claude Code execution index lists the helpers of opencode-routed workers.
