> **⚠ POST-HOC RECORD** — This proposal was backfilled after implementation against a user-supplied statement of intent. It describes a decision already made, not one being proposed.

## Why

Backfill's most common caller is now a machine composing the invocation, yet the contract forbade skipping questions regardless of data already supplied — blocking automation and wasting human round-trips. The implementation removes those round-trips wherever the invocation already carries the answers: a pasted sai-explore crystallized block supplies structured intent, a diff-source token selects the diff, and `--fast-track` trades the three remaining gates for a data-complete run that closes with zero questions while every interactive path stays byte-compatible.

## What Changes

- `sai/commands/backfill/instructions.md` — new Envelope Tokens section parsing `--staged | --unstaged | --diff <sha>` and `--fast-track` worker-side with the trimmed request body as remainder; Phase 1 takes a token-resolved diff source directly and halts on empty staged input; Phase 2 gains crystallized-block intake replacing the intent-capture choice with three-step label → mine → ask field resolution; Phase 3 pre-resolves Questions 1–2 from the block before asking and skips generated reconciliation questions under fast-track (items stay non-normative); Phase 4 auto-proceeds the conflict decision under fast-track carrying the report verbatim; Phase 5 orders name precedence arguments > block > derived > STOP with fast-track acceptance.
- `sai/commands/backfill/worker.md` — declares worker-owned envelope parsing and `fast_track_active` session state, the unattended zero-needs_input lifecycle goal, conditional ask returns for every gated question, and the empty-staged halt literal.
- `sai/commands/backfill/coordinator.md` — routes unattended envelopes directly from dispatch to coordinator-owned validation and execution, presenting worker payload content unaltered.
- `AGENTS.md` — documents `sai-backfill` as the fifth fast-track opt-in with its fixed opt-out set; safe-operations confirmations, hard halts, and the MANDATORY STOP literal remain in force.

## Capabilities

### New Capabilities

- backfill-unattended-intake: pinned-label detection of crystallized blocks with three-step field resolution (label → free-form prompt mining → ask), replacing intent capture and answering Q1/Q2 when derivable
- backfill-diff-source-token: `--staged | --unstaged | --diff <sha>` parsed worker-side from arguments_value; missing token restores the normal ask; empty staged input halts with the remediation literal
- backfill-fast-track: fifth opt-in command whose fixed opt-out set is reconciliation questions skipped (items stay non-normative), spec-conflict reported verbatim then auto-proceeded, and crystallized-block change-name confirmation auto-accepted

### Modified Capabilities

- sai-fast-track-flag: canonical membership list grows from four to five commands; backfill parses in its worker card alongside the diff-source tokens with no banner
- backfill-diff-selection: token-direct selection bypasses the interactive ask whenever a diff-source token is present
- backfill-interview: fixed questions are pre-resolved through the block chain before any is presented
- backfill-sequential-interview: sequential presentation applies only to questions left unanswered after resolution
- backfill-conflict-detection: the proceed-or-abort decision gains a fast-track auto-proceed branch after the verbatim report
- backfill-intent-reconciliation: block intake precedes the capture choice, bounded questions are skipped under fast-track, and the write gate completes on gate-resolution by data
