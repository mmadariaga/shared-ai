## Why

Managed agents previously began with bare `Fetch @sai/...` directives without fetch-resolution rules in scope, so cold-context subagents could search broadly and load an unintended repository copy. The implemented bootstraps make harness-specific fetch resolution available before policy or worker-contract loading, while the Claude Code budget-explorer receives the `Skill` tool needed to execute its bootstrap.

## What Changes

- Add `Fetch @skills/fetch/SKILL.md` as the first body line of Claude Code generic-agent sources and generated worker agents.
- Add `Fetch @~/.config/opencode/skills/fetch/SKILL.md before you continue.` as the first body line of opencode generic-agent sources and generated worker agents.
- Grant the `Skill` tool to the Claude Code `budget-explorer` agent.
- Extend canonical-agent, installer, and worker-matrix tests to require the harness-specific bootstrap before the canonical fetch.

## Capabilities

### New Capabilities

- `agent-file-fetch-bootstrap`: Managed agent projections bootstrap harness-specific `Fetch @` resolution before loading their canonical policy or worker contract.
- `budget-explorer-skill-access`: The Claude Code `budget-explorer` agent can execute the fetch-skill bootstrap through its declared `Skill` tool.

### Modified Capabilities

- `claude-fetch-resolution`: Claude managed agents now bootstrap the Claude fetch skill before their canonical Fetch directives.
- `fetch-resolution-path-scoping`: Opencode managed agents now use the absolute user-global fetch-skill directive that remains within the `skills/` namespace.
- `canonical-opencode-agent-behavior`: Generic agent bodies now contain the bootstrap followed by the canonical policy Fetch.
- `claude-budget-agent-tunables`: Claude generic sources add the bootstrap and give `budget-explorer` the `Skill` tool.
- `opencode-generic-agent-files`: Opencode generic agent bodies add the harness bootstrap before their policy Fetch.
- `worker-matrix-collapse`: Generated worker bodies add the harness bootstrap before their canonical worker-contract Fetch.
- `managed-worker-registry`: Managed worker projection bytes and regression coverage include the new bootstrap.
