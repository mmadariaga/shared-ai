## Why

`sai-backfill` was the last command still shipped in the legacy utility shape after the commit and archive migrations: a single `body.md` executed entirely in the main session, fusing the interactive interview, delegated conflict scanning, draft composition, schema validation, and the final artifact writes in one context. Backfill's write surface is exactly the kind of thing the routed architecture isolates — the coordinator alone validates drafts against the sai-workflow schema and writes into `openspec/changes/{name}/` — while interviewing and mechanical diff work are exactly what a budget-tier managed worker should absorb. Replicating the commit/archive pilot pattern removes the last special case from both boot adapters' routing tables and gives `sai-backfill` the same closed lifecycle payloads, changed-files union, and reconstruction fields every other routed command carries.
