> **⚠ POST-HOC RECORD** — This proposal was backfilled after implementation against a user-supplied statement of intent. It describes a decision already made, not one being proposed.

## Why

Change telemetry existed only for opencode: on Claude Code the collector `sai/tools/change-telemetry.js` always returned `skipped`, although the Claude Code session transcripts already hold most of the same data (`sai/tools/retrospective.js` already read them). A project that enabled `experimental.changeTelemetry` therefore got no `telemetry.md` for runs made on Claude Code.

## What Changes

- New shared, read-only Claude Code transcript reader `sai/tools/claude-transcripts.js`. It locates `<config>/projects/<encoded-project>/<session>.jsonl` and `<session>/subagents/agent-<id>.{jsonl,meta.json}` (config folder from `CLAUDE_CONFIG_DIR`, default `~/.claude`), collapses the lines of one assistant response into one request by `message.id`, counts each tool call once by its `tool_use` id, marks a call as an error when its `tool_result` carries `is_error: true`, and counts each `Agent` call as one dispatch. It exposes `openClaudeSource`, which answers the same questions as the opencode source.
- `sai/tools/change-telemetry.js` reads through a harness source with one shape on both harnesses (`opencode.db` on opencode, the transcripts on Claude Code), selected by `--harness`. The Claude Code skip branch of `collect` is removed:
  - a direct `/sai-plan` or `/sai-build` is anchored on its `<command-name>` record in the session transcript; an in-session `/sai-explore` route is anchored on the `agentType` of its worker subagents, and its execution id combines the session id and the anchor record id;
  - Claude Code rows report `cost`, `reasoning`, and `variant` as `unavailable` in every row and total, never `0`, and each Claude Code section carries a note saying so;
  - `Cache write` is the sum of the 5-minute and 1-hour cache creation tokens, or the unsplit value when the transcript has no split;
  - every section names its harness (`Harness: Claude Code` or `Harness: opencode`), and a change total over executions from both harnesses is marked partial for a field an execution lacks;
  - a missing or unreadable transcript folder, or an execution that is not in the session transcripts, returns `skipped` with the reason and writes nothing;
  - the `/sai-build` first-review tally also recognizes the Claude Code write tools (`Write`, `Edit`, `MultiEdit`);
  - a Claude Code collection records no `## Exploration` section, and `explore-origin` still skips on Claude Code, now saying that recording the explore origin on Claude Code is not supported yet.
- `sai/tools/retrospective.js` reads Claude Code transcripts through the shared reader instead of requiring the cache-benchmark skill's `adapters.js`; its opencode token reading moves into the tool itself.
- `sai/policies/change-telemetry.md`, `docs/project-settings.md`, and the `AGENTS.md` repository-structure row of `retrospective.js` describe telemetry on both harnesses and the fields Claude Code does not record.
- `test/change-telemetry.test.js` replaces the Claude Code skip assertion with collection tests over Claude Code transcript fixtures.

## Capabilities

### New Capabilities

None

### Modified Capabilities

- `change-telemetry`: the collector measures executions on Claude Code from the session transcripts, under the same `experimental.changeTelemetry` setting as opencode, with `cost`, `reasoning`, and `variant` unavailable and each section naming its harness.
- `sai-retrospective`: the Claude Code transcript source is the shared reader `sai/tools/claude-transcripts.js`, with unchanged output.

## Impact

- New: `sai/tools/claude-transcripts.js`
- Modified: `sai/tools/change-telemetry.js`, `sai/tools/retrospective.js`, `sai/policies/change-telemetry.md`, `docs/project-settings.md`, `AGENTS.md`, `test/change-telemetry.test.js`
- Unchanged by design: `skills/universal/sai-context-cache-ttl-benchmark/adapters.js`, the opencode collection output, and the settings catalogue (one `experimental.changeTelemetry` setting serves both harnesses).
- Known limitations: Claude Code rows carry no cost, reasoning, or variant, so change totals over mixed-harness executions are partial; the transcript reading logic is duplicated for a while between `adapters.js` and the shared reader; a project that already enabled the setting for opencode now also records Claude Code runs; recording the explore origin on Claude Code is left to a later change.

Out of scope: design.md, tasks.md, implementation.md — not generated by /sai-backfill
