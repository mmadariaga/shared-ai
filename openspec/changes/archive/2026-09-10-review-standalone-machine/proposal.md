## Why

Standalone `sai-5` derives its active-step pointer from prose in the shared runner. The coordinator applies "the first declared step still unmarked in plan order" as judgment rather than as code, reproducing the same advisory-pointer drift that `implement-standalone@1` removed for `sai-3`. Review is a fully step-gated phase adapter whose routing remains prose-derived and implicit rather than state-governed.

## What Changes

The change adds `review-standalone@1`, a new stage machine that owns happy-path step routing for standalone `/sai-5-review` runs. The machine replicates the established pattern from `implement-standalone@1` and `spec-standalone@1`, providing closed-state step sequencing, just-in-time step file loads, minimal wire protocol, and fail-closed behavior.

Implementation details:
- New file `sai-state/machines/review-standalone.js` (185 lines) implementing the five-step stage table: `resolve-change`, `establish-diff-scope`, `resolve-review-analysis`, `resolve-mutation-analysis`, `close-review-outcome`
- Registry entry added to `sai-state/registry.js` (1 line)
- Comprehensive test suite `test/review-standalone-machine.test.js` (175 lines) covering progression, silence on undeclared ids, stale-stage re-resolution, and monotonic marking

The machine operates only in standalone mode; the composed meta-review path (position 0 non-final) retains today's dispatcher behavior unchanged, with no shared sessions or state between the two routing paths.

## Capabilities

### New Capabilities

#### Capability: review-standalone-loading

Stage-machine-owned step routing for `/sai-5-review` standalone runs with:

- **Closed states**: Five declared progress steps plus terminal done, no wait or failure states
- **Just-in-time step loads**: Each step file loads only when `next.follow` names it; initial dispatch runs from nucleus only
- **Minimal wire**: Stage and pointer-only travel; mandatory machineId on each emit; no snapshots or state in requests
- **Cursor dedup**: Already-loaded step paths are not re-fetched
- **Standalone-only scope**: The machine arbitrates only when the adapter runs as sole adapter; the composed path never consults it
- **Fail-closed behavior**: Unknown follow targets or paths outside `steps/` stop with error; no Bounded Recovery routing

The machine receives signal as `{ step_ids: [...] }` (worker-reported completed ids) with `completedIds` accepted as tolerant alias. Undeclared ids are ignored silently with no notification channel; the coordinator re-emits the authoritative pointer which re-steers the worker. Marks are monotonic and never reopened.

### Modified Capabilities

None. The change introduces no modifications to existing capabilities. The meta-review composed path (`/sai-review` position 0) keeps its existing `step_pointer_map` derivation byte-identical.
