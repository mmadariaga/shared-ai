## Why

Bring existing GitHub backlog work into the current conversation, including an active sai-explore session, without manually copying it. This complements to-backlog publication while leaving discussion and exploration progression under user control.

## What Changes

- Added an explicitly invoked from-backlog skill with four ordered steps and checkable completion criteria.
- Added faithful issue incorporation with source provenance, title and description as requested-work authority, and comments as unverified brainstorming.
- Added registry-driven GitHub reference resolution and separate read-only helpers using structured gh GraphQL queries, issue type checking, and complete comment pagination.
- Added explicit missing-description, retrieval-failure, incomplete-delivery, and conversation-capacity handling.
- Added conversation-preserving Claude Code and opencode command entries, mirrored provider-reference installation, and a dedicated read-helper capability profile.
- Added simulated GitHub responses, reference and pagination tests, instruction-contract checks, CLI coverage, and mirrored installation assertions.
- Updated command-directory and command-enumeration tests for twenty-one commands without changing the nineteen-command SAI set.
- Documented invocation, reference formats, dependencies, and initial provider scope.

## Capabilities

### New Capabilities

- `from-backlog-conversation-import`: Explicit, faithful, read-only issue import into the active conversation with separate content authority levels and accurate delivery outcomes.
- `from-backlog-provider-resolution`: Concrete GitHub issue resolution and structured retrieval through a provider registry and separate adapter.
- `from-backlog-harness-installation`: Equivalent command entries, installation surfaces, documentation, and regression coverage for both supported harnesses.

### Modified Capabilities

- `command-wrapper-body`: Source wrapper directories contain nineteen SAI wrappers plus both conversation-preserving backlog commands.
- `sai-1-command-inventory`: Both harness inventories enumerate twenty-one manifest-declared commands, including from-backlog.
- `contract-tool-capabilities`: The additional import command has a resolvable read-only helper profile.
