## Why

The previous root-relative `Glob(".codegraph/*")` probe could return no match even when the project-root `.codegraph` directory contained `codegraph.db`. That false negative produced a misleading no-index warning and `codegraph init -i` guidance even though the CodeGraph structural query succeeded.

## What Changes

The `sai-explore` research-tooling check now uses a read-only directory-scoped `Glob` with `path: .codegraph` and `pattern: *` at the project root. It treats the index as present only when the root-scoped results contain an entry other than `.gitignore`, so sentinel-only, absent, and nested-only directories remain unavailable. The check remains one-time, non-blocking, read-only, and preserves the exact English notices.

Regression coverage verifies an existing root index, an absent directory, a sentinel-only directory, and a nested-only directory. The contract-preservation coverage records the intentional wording difference.
