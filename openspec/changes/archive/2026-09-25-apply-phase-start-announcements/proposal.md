## Why

The current run shows worker dispatch details, but the step position is not consistently visible at the start of each RED and GREEN phase.

## What Changes

The shared apply runner now prints an announcement immediately before each RED or GREEN worker dispatch. It prints exactly `RED N/M` for `red` and `green-exception` dispatches, and exactly `GREEN N/M` for `green` and `green-direct` dispatches. `N` is the active Step number, and `M` counts all `#### Step N:` headings in `implementation.md`, including completed Steps. Same-worker continuations and recoveries do not repeat an announcement, and omitted phases produce no announcement. The shared runner rule applies to standalone apply and the chained build apply segment. Architecture tests pin the format, denominator, completed-Step handling, continuation/recovery handling, and omitted-phase behavior.
