## Why

Prose-based research-tooling detection in the explore prompt is verbose and fragile; moving detection into a deterministic script gives a single testable source while the explore prompt stays lean.

## What Changes

- Add `sai/tools/research-tools-check.js` as the deterministic research-tooling probe: filesystem-only signals (project-root `.codegraph/` readdir filtering `.gitignore` plus `codegraph --version` binary probe), explicit `--mcp-present true|false` caller input with no script inference, three advisory states (`ready`, `no-index`, `not-installed`) with verbatim English literals, and read-only non-blocking execution exiting 0 on any status and 2 only on usage or IO errors.
- Update `sai/commands/explore/body.md` to run the probe inline in the main session with no subagent immediately after the prereqs `verdict: pass` and before Load behaviors and the first research, using the first existing tool-location candidate with the script filename substituted, running once per session with no reprint on later turns, relaying advisory results without halting or writing files, and running nothing when prereqs halt or cannot be completed.
- Simplify `sai/commands/explore/instructions.md` item 2 to a one-line rule that prints the `literal` returned by the script verbatim in English without re-deriving, repeating, or translating it, removing the prior prompt-side tool and Glob detection prose.

## Capabilities

### New Capabilities

- `explore-research-tooling-probe`: Deterministic filesystem probe that returns the advisory status and verbatim literal for explore research tooling.

### Modified Capabilities

- `explore-codegraph-fallback-notice`: Detection moves from prompt-side tool presence and Glob prose to the script probe ordered after prereqs, with sentinel-only handling and verbatim English relay preserved.
- `explore-instruction-delivery`: Instruction item 2 becomes the one-line literal-print rule with execution owned by `body.md` between prereqs pass and first research.

## Impact

- **New files**: `sai/tools/research-tools-check.js`.
- **Modified files**: `sai/commands/explore/body.md`, `sai/commands/explore/instructions.md`.
- **Known limitations**: One more maintained tool versus about twenty lines of prompt bloat; early single notice versus late per-task discard relay. The script cannot observe MCP deferred tools, so MCP presence arrives as explicit caller input or stays in prompt. Fix-loop round 1 converged with no block-related findings; reported npm test failures are pre-existing and verified against the stashed baseline, not introduced by this change.
