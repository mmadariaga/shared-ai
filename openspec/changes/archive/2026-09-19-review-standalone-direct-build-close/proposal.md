## Why
Standalone review today ends with `Review done.` and manual fix guidance, while `/sai-review` offers a two-option Direct Build fix plus one local commit. Porting that close gives the same findings-driven fix path in standalone review without running the audit suite first.

## What Changes
- Extends `sai/commands/review/coordinator.md` terminal navigation with a findings-driven Direct Build close that reads the freshly generated `review.md` plus on-disk audits as-is.
- Adds a two-option selector (Direct Build / Do not implement anything now) shown only when findings remain.
- Reuses the existing `sai-review-fix-worker` with a 3-round fix loop, conditional backfill, path-scoped staging, and one pre-authorized local HEREDOC commit.
- Extends the no-commit guard surface to the execute window with `allow_commit` carried only there.

## Capabilities
### New Capabilities
- `standalone-close-selector` — findings-conditional two-option close with identical standard close text.
- `findings-driven-fix` — reused fix worker loop, conditional backfill, and single-commit local close.

### Modified Capabilities
- None — no existing standalone capability behavior is modified; the change adds the close.
