## Why

Model customization starts with all targets selected, so clearing the list currently requires many individual key presses. A single shortcut makes bulk selection practical while keeping its behavior predictable for mixed selections.

## What Changes

- `bin/install-flow.js` adds opt-in `toggleAll` behavior to the shared multi-select checklist engine. `Ctrl+A` uses the first selectable checkbox as its reference, sets all selectable rows to the opposite state, skips separators, preserves the cursor position, redraws, and does not confirm.
- `bin/model-customization.js` enables the behavior on customization and reset target checklists and adds it to the visible checklist legend.
- Tests cover mixed selections, all-checked and cleared states, separators, empty-confirmation protection, unrelated checklists, single-select menus, and both OpenCode and Claude Code paths.
