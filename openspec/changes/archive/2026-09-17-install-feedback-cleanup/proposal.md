## Why

The Opencode config notice printed twice: once via the `merge-jsonc` projection path (`installProjection` at `bin/install-flow.js:888` through `installOpencode`) and again via an explicit second `copyOpencodeConfig` call in `main` (`bin/install-flow.js:1325-1326`). Interleaved conditional `console.log` lines from the install offers split the per-harness summary ordering, forcing manual verification of what the installer did.

## What Changes

- `bin/install-flow.js` only. Added `emitInstallerNotice(notices, line)` helper that appends to a notices array when present and falls back to `console.log` otherwise.
- Threaded an optional `notices` collection through `offerOpencodeInstall`, `offerCodegraphInstall`, `installProjection`, `installOpencode`, `printOpencodeConfigMessage`, and `copyOpencodeConfig`; all actionable lines (opencode install command, CodeGraph CLI and MCP commands, wiring hint, created-from-reference line, verify block, migration notice, merge messages) now route through it instead of printing inline.
- Removed the explicit second `copyOpencodeConfig` call in `main`, leaving the `merge-jsonc` projection as the sole config-merge path.
- Reordered `main()` emission per harness: Claude block with its paths, then Opencode block with its paths; deduped collected notices via a Set and printed them once in a single final block, followed by a single setup reminder with no stray blank lines.
- Extended the verify and fresh-create messages to cite `configs/opencode.jsonc` as the reference example.

## Capabilities

### New Capabilities

- installer-feedback-grouping: grouped per-harness output with paths at each block close.
- actionable-notices-summary: single final deduplicated block for verify, migration, permission, setup, and wiring notes.
- example-config-reference: citation of `configs/opencode.jsonc` when the config is missing or manual verification is required.

### Modified Capabilities

- None. No existing capability was modified as a named capability; the change defers and regroups existing messages from `installer-post-install-summaries`, `opencode-config-message`, `opencode-config-install`, `installer-config-guidance`, `installer-opencode-cli-bootstrap`, and `installer-codegraph-cli-bootstrap` without renaming those capabilities.
