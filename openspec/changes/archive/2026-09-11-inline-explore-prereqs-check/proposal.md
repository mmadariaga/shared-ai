## Why
The OpenSpec prerequisite preflight is a deterministic script with a closed verdict. Wrapping it in a budget subagent costs about 25 seconds plus extra reads to transport a pass/halt verdict that needs no synthesis, so the explore main session runs the check inline.

## What Changes
- `sai/commands/explore/body.md` runs the `sai/tools/prereqs.js` `check` sub-command inline in the main session with no subagent and no deferral condition, on every invocation including sessions that never touch `openspec/`.
- Tool selection uses the first existing candidate in `sai/policies/prereqs-check.md` order, project-local relative path first then verbatim global, and never joins a root string to a suffix.
- Invocation stays byte-identical per harness as `node <tool-path> check --json --cwd <project-root> --require-openspec-skills <harness>`; omitting the flag or passing any other value is a usage error (exit 2), never a halt.
- Verdict relay is direct: exit 0 (`verdict: pass`) continues exploration; exit 1 (`verdict: halt`) prints the matching remediation literal unchanged and stops without writing any file; exit 2, unlocatable tool, or unparseable payload is reported as-is with no literal and the run does not continue as passed.
- Removed the single budget-subagent dispatch, its dedicated prompt, and its four-field verdict envelope.

## Capabilities
### New Capabilities
- None — every behavior modifies an existing capability.

### Modified Capabilities
- `explore-prereqs-delegation` — delegated execution becomes inline execution with direct verdict relay.
- `prerequisite-preflight` — delegation sentence becomes inline execution with identical invocation and trichotomy.

## Impact
- Modified: `sai/commands/explore/body.md` — prerequisite preflight runs inline in the main session.
- New retroactive records for this change: `openspec/changes/inline-explore-prereqs-check/.openspec.yaml`, `proposal.md`, `specs/explore-prereqs-delegation/spec.md`, `specs/prerequisite-preflight/spec.md`.
- Known limitation: a future command could reintroduce subagent delegation; accepted impact is one session's latency with no correctness risk.
