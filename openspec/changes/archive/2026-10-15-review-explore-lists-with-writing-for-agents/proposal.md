> **⚠ POST-HOC RECORD** — This proposal was backfilled after implementation against a user-supplied statement of intent. It describes a decision already made, not one being proposed.

## Why

The `writing-for-agents` skill only shaped the initial draft of the Explore edge-case and implementation-detail lists. On edge-case lists, the probe corrections landed after that draft, so the list the user saw never got a wording review.

## What Changes

- `sai/commands/explore/list-writing.md` stays the single source for list wording and now owns the full sequence: load or reuse the skill, draft, review pass, display.
  - **Review pass**: a second, silent pass of the skill over the complete list, run inline in the Explore session with the already-loaded skill. The user sees only the reviewed list, with no change marks and no review notes.
  - **Revised lists**: after every user adjustment, the review pass runs again over the complete updated list before it is displayed.
  - **Empty list**: an empty list is displayed directly as `- None` and skips the review pass.
  - **Wording only**: the draft and the review pass change phrasing alone; the item set, each item's meaning, and the `E`/`I` numbering stay as drafted, and neither pass adds a technical decision or behavior.
  - **Warning**: the unavailable-skill warning now reads `Warning: the writing-for-agents skill is unavailable, so the list is shown without its review.`, keeps the once-per-invocation rule, and the review pass is skipped.
- `sai/commands/explore/steps/review-edge-cases.md` and `sai/commands/explore/steps/implementation-details.md` replace `Use the writing-for-agents skill to create the list.` with a pointer to the shared sequence. On edge-case lists, the review pass runs after the lightweight probes' private corrections and before the one-message emission.
- `docs/skills.md` and `docs/commands/sai-explore.md` describe the draft, review pass, and display sequence and the reworded warning.
- Test case I6 in `test/install-writing-for-agents.test.js` asserts the shared sequence, the review-after-probes order, the reworded warning, and the removal of the "create the list" sentence for both list stages.

Rejected alternative: an independent subagent reviewing each list. It would need the idea context transferred and would add the two-phase explorer startup to every list and revision.

## Capabilities

### New Capabilities

- None

### Modified Capabilities

- `explore-edge-case-review`: the edge-case list gains a silent wording review pass after the probes and before display, re-run on every revised list, skipped for an empty list, with the reworded unavailable-skill warning.
- `explore-implementation-details`: the implementation-detail list gains the same silent wording review pass before display, re-run on every revised list, with the reworded unavailable-skill warning.
