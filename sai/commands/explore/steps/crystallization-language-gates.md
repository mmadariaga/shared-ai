    **Overview-language gate (gate 9, sai-explore only).** When this turn is an explicit crystallize request — the same trigger list as gate 8 — and the user did not supply an explicit `--overview-lang <language>` option, always evaluate this gate after gate 8 resolves and before printing any `Ready to Propose` block.     1. **Tracked target**: the current crystallized idea or slice set.
